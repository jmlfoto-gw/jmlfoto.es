# jmlfoto.es

Web personal oficial de **Jose Morales** (`jmlfoto`), fotógrafo especializado en conciertos, naturaleza, patrimonio histórico y proyectos documentales con base en Madrid, España.

Sitio publicado en: [https://jmlfoto.es/](https://jmlfoto.es/)

## Descripción

Este repositorio contiene el código fuente de la web estática de `jmlfoto.es`, desarrollada con HTML, CSS y JavaScript y publicada mediante GitHub Pages.

La web reúne portfolio fotográfico, proyectos editoriales, blog, contacto y acceso a copias fotográficas de autor.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Estructura del proyecto

- `index.html`: página principal.
- `style.css`: estilos del sitio.
- `script.js`: interacciones del front-end.
- `cookies.js`: gestión de consentimiento y scripts asociados.
- `privacidad.html`: política de privacidad.
- `aviso-legal.html`: aviso legal.
- `robots.txt`: directrices para rastreadores.
- `sitemap.xml`: mapa del sitio.
- `CNAME`: dominio personalizado.
- `assets/`: imágenes y recursos gráficos.
