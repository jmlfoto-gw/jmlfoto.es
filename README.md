# jmlfoto.es

Web personal oficial de **Jose Morales** (`jmlfoto`), fotógrafo especializado en conciertos, naturaleza, patrimonio histórico y proyectos documentales con base en Madrid, España. [page:45]

Sitio publicado en: [https://jmlfoto.es/](https://jmlfoto.es/) [page:45]

## Descripción

Este repositorio contiene el código fuente de la web estática de `jmlfoto.es`, desarrollada con HTML, CSS y JavaScript vanilla, y publicada mediante GitHub Pages. [page:45]

La web reúne portfolio fotográfico, proyectos editoriales, blog, contacto y acceso a copias fotográficas de autor. [page:45]

## Tecnologías

- HTML5. [page:45]
- CSS3. [page:45]
- JavaScript. [page:45]
- GitHub Pages para despliegue. [page:45]

## Estructura del proyecto

- `index.html`: página principal. [page:45]
- `style.css`: estilos del sitio. [page:45]
- `script.js`: interacciones y comportamiento del front-end. [page:45]
- `cookies.js`: gestión de consentimiento y scripts asociados. [page:45]
- `assets/`: imágenes y recursos gráficos. [page:45]
- `privacidad.html` y `aviso-legal.html`: páginas legales. [page:45]
